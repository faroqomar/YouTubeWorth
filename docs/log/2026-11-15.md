# 2026-11-15: Conservative filler validation and fewer model calls

## Problem

The pipeline repeated the whole-excerpt classification for single-cue filler candidates, accepted different filler categories across parts, and performed follow-up inference for disabled categories. It also classified factual content before determining whether any usable quote existed.

## Implemented

- Components: `worth_analysis.py`, `classifier-config.json`, Python regression fixtures and analysis documentation.
- Require two nonempty cue groups with matching whole/part categories; preserve single-cue candidates as context.
- Skip filler follow-ups for disabled categories or truncated input; stop after the first failed part.
- Extract candidate quotes before optional factual classification.
- Advance classifier identity to invalidate previous cached judgments.
