# Public demo media

The November 27, 2026 capture uses the unpacked Chrome extension and Worth's local Laya service on Apple Silicon. The public video is [How does Claude Code actually work? by Theo - t3.gg](https://www.youtube.com/watch?v=I82j7AzMU80). The source footage belongs to its respective owners.

`demo.gif` and `demo.mp4` show an edited sequence of Chrome captures. Worth reads captions and displays the viewing map. The recording then shows **Useful only**, a click on the passage that starts at 8:19, and the YouTube player paused at 8:19 with green markers above its timeline. The edit shortens waits and omits audio.

The extension read 1,188 English caption timestamps. A live run displayed local Laya progress across 91 excerpts. Worth suggested 33:06 of useful passages and 6:16 of optional context for the 39:22 video. These are model suggestions. The capture did not measure classifier accuracy or processing speed.

- `viewing-map.png` shows the side panel before filtering.
- `useful-only.png` shows the filtered map and the verified jump to 8:19.
- `settings.png` shows the viewing goal and options for filler detection and player highlights.

The captures crop away Chrome controls, account controls and video recommendations. Captions sit outside the captured UI. The package includes these five public media files. Raw captures and local account data stay outside the package.

The November 8 capture used the same public video and demonstrated a jump to 4:52. The earlier assets and capture notes are available in Git history.
